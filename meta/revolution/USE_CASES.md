# Сценарии использования
- Построение смысловых деревьев
- Рост и взаимосвязь сущностей
- Генерация по тексту, автодополнение структур
- Визуализация онтологий через d3.js граф
- Автономный автоген: текстовое намерение → создание/связывание/удаление сущностей
- Интеграция с LLM для интерпретации сложных намерений
