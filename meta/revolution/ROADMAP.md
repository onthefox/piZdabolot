# Adapt SymbioSystem: Roadmap
- **MVP**: запуск базовой экосистемы с графом, автогеном и UI.
- **Эволюция**: расширяемые типы намерений, расширение стилей отображения.
- **Экспансия**: подключение внешних источников, интеграция с LLM.
- **Фаза 2**: LLM-powered intent parsing, multi-agent swarm, persistent memory.
- **Фаза 3**: External API integrations, real-time collaboration, ontology auto-expansion.
