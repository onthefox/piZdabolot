Почему SymbioSystem?

AI-ассистенты — одноразовые. SymbioSystem — живая экосистема.

Традиционные AI

  • Одноразовые запросы без контекста
  • Нет визуализации связей
  • Статические ответы
  • Нет автономности
  • Нет эволюции системы

SymbioSystem

  • Контекстная память намерений
  • MindPalace: живой граф смыслов
  • Растущая онтология
  • Автономный движок: намерение → действие
  • Эволюция через Autogen

Архитектура

6 модулей, 3 слоя, 1 экосистема

🧠

SymbioCore

Интерпретация намерений. Парсинг команд, валидация, обработка ошибок.

MVP готово
🐝

SymbioHive

Живая экосистема: онтология, сущности, связи. CRUD + статистика.

MVP готово
⚡

SymbioFlow

Автономный движок: приём → план → выполнение. Anti-loop защита.

MVP готово
🤖

Autogen

Автогенерация сущностей и связей по текстовому описанию.

MVP готово

MVP готово

React + d3.js force-directed граф. Карточки сущностей.

Быстрый старт

Одна команда — полный стек

# Поднять весь стек $ make up # Отправить намерение $ curl -X POST http://localhost:8000/intent \ -H "Content-Type: application/json" \ -d '{"intent": "создать Проект Адаптация"}' # Ответ { "action": "create", "created": { "id": 1, "name": "Проект Адаптация" } }
